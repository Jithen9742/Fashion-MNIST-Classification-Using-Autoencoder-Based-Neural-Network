This project builds a neural network for classifying images from the Fashion MNIST dataset, which consists of 10 categories of clothing and accessories. The images are preprocessed by normalizing pixel values and reshaping them into a flat 784-dimensional vector. The model is a simple autoencoder-based classifier, where an encoded representation (latent space of 64 neurons) is learned before passing through a dense softmax layer for classification. The model is trained using categorical cross-entropy loss and the Adam optimizer for efficient learning. Performance is tracked using training accuracy, validation loss, and loss curves plotted with Matplotlib. The final trained model achieves high accuracy and can effectively classify unseen fashion items.
